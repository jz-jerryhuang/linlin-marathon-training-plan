## 📌 核心特色

- **琳琳專屬客製化體能配置**：以「7~8 速 9K、6~7 速 5K」為體能診斷基礎，溫和拉長跑量，嚴禁逞快。
- **雙階段漸進課表**：
  - **第 1 階段：半馬穩健推進（第 1 - 6 週）**：無痛銜接至 16K Peak，備戰 11/14 半馬（目標 2h 35m ~ 2h 48m）。
  - **第 2 階段：全馬初征大躍進（第 7 - 14 週）**：賽後主動修復後邁向 18K、22K、25K 與 28K 終極考驗，備戰 01/10 首馬（目標 5h 25m ~ 5h 45m）。
- **進度自動保存**：每堂課表可即時勾選打卡，狀態自動保存於瀏覽器 LocalStorage，重新整理頁面進度不遺失。
- **琳琳專屬訓練配速區間**：E 速 (7:50~8:30)、MP 全馬巡航速 (7:30~7:55)、HM 節奏 (6:45~7:15)、LSD (7:50~8:20)。
- **配速完賽時間試算機**：即時換算 5K、10K、半馬與全馬完賽預估時間。
- **補給時間表與防傷三大鐵則**：能量膠定時補充、水站降速心法、小步頻防傷策略。
